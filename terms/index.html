The free first class

The first live class in any cohort is genuinely free. No card, no commitment. You can leave halfway through and never come back. We'd only ask that if you reserve a spot and can't make it, you let us know in advance so we can offer the place to someone else.

The £299 course

If you continue after class 1, the remaining four classes cost £299 in total. Payment is taken once, in advance, before class 2.

What's included: all five live classes, recordings of every session for lifetime access, class materials and templates, and lifetime access to the alumni WhatsApp community.

Refunds

If you decide the course isn't for you after paying, email hello@takeawai.com before class 4 and we'll refund you in full. After class 4 we can't offer a refund, but you keep lifetime access to recordings and the alumni community regardless.

Every class is recorded. If you can't make a live session, watch the recording before the next one. Recordings are yours to keep.

We aim to run cohorts on the dates advertised. If we ever have to move a date, we'll give you as much notice as possible and offer either a place in the rescheduled cohort or a full refund.
